## Анализ алгоритмической сложности

1. **Быстрое возведение матрицы в степень:**
    - Временная сложность: O(log N)
    Алгоритм использует быстрое возведение в степень (методом умножения матриц). Количество операций умножения матриц пропорционально log(N). Так как размер матрицы фиксирован, то каждое умножение выполняется за константное время.

2. **Рекурсивный алгоритм (без кеширования):**
    - Временная сложность: O(2^N)
    Это наивный подход, при котором одни и те же подзадачи пересчитываются экспоненциальное количество раз.

3. **Итеративный алгоритм:**
    - Временная сложность: O(N)
    Этот метод вычисляет числа Фибоначчи использует простой цикл, выполняющийся N раз. Линейно зависит от N, зато занимает константное количество памяти.

4. **ДП:**
    - Временная сложность: O(N)
    Похож на простой рекурсивный подход, но сохраняет результат каждой подзадачи, чтобы она вычислялась только один раз. Это снижает сложность с экспоненциальной до линейной ценой использования памяти O(N) для хранения таблицы результатов.
